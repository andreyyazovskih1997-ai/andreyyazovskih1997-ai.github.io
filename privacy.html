Privacy policy

This policy describes the personal Windows application Amber Hour Noir Local Uploader and this informational website.

Google data accessed

With the owner's consent, the application receives OAuth access and refresh credentials, the connected YouTube channel's identifier and title, and information about videos it uploads, including their identifiers, privacy status and processing status. It requests only youtube.upload and youtube.readonly.

The application uses these data to confirm that it is connected to the intended channel, transfer the finished video, set the thumbnail, resume interrupted transfers and check that a private review copy is ready.

Local media and storage

Source audio, artwork and animation are processed in local project folders. The completed video, thumbnail and publication metadata are sent to YouTube at the owner's direction. Source MP3s and animation files are not separately uploaded by the application.

OAuth credentials and resumable upload session details are encrypted with Windows Data Protection and stored on the owner's computer for the current Windows user. Local project state and reports contain video identifiers, processing state and YouTube Studio links. The application has no application-operated server for storing these data.

Sharing and use restrictions

Google user data are used only for the upload and verification functions described here. The application does not sell these data, use them for advertising, or send them to AI models for training or inference. It does not transfer Google user data to another application or third-party service.

Use and transfer of Google user data follow the Google API Services User Data Policy, including its Limited Use requirements. YouTube processes uploaded content under its own policies.

Retention, revocation and deletion

Local media, reports and encrypted connection data remain on the owner's computer until the owner removes them. The owner can stop the background program and revoke its Google access on the Google account connections page. Local connection data can then be removed from the application's local private storage.

Revoking access or removing local files does not delete an uploaded YouTube video. Uploaded copies are managed separately in YouTube Studio.

This website

These pages contain no application analytics, advertising scripts, forms or embedded media. GitHub Pages hosts the website and may process visitors' IP addresses and other request data for security and service operation, as described in the GitHub Privacy Statement. Visiting this website does not connect a YouTube account to the desktop application.
