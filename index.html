Amber Hour Noir
Local Uploader

Prepare a music video on Windows. Upload a private copy to YouTube. Review it before publishing.

What the application does

The application watches selected local project folders, checks the approved artwork and supplied media, renders the video, and prepares a captioned thumbnail, title, description, chapters and tags. It uploads the finished package to the owner's Amber Hour Noir channel with private visibility.

The owner reviews the artwork and animation before rendering and decides when to publish a completed video in YouTube Studio. The application does not publish videos publicly.

Why it connects to Google

The application requests youtube.upload to upload the video and set its thumbnail, and youtube.readonly to verify the channel identity, uploaded video's visibility and processing state. Access is requested through Google's consent screen. The application does not ask for the Google account password.

A local workflow

This is a personal utility for the channel owner, not a public upload service. Rendering and project management run on the owner's computer. Connection credentials are encrypted using Windows Data Protection for the current Windows user.
